Bot Flow Summary
1. POST { action: "poll" }           → get submissions[]
2. POST { action: "claim", submission_id: "abc123" }  → lock it
3. Run Playwright: fill MAS portal form, attach files, submit
4a. POST { action: "complete", submission_id: "abc123", portal_ticket_id: "TKT-999" }
4b. POST { action: "fail", submission_id: "abc123", error_message: "..." }
Key notes for the dev:

attachment_urls and evidence_files are JSON strings — parse them to get file URL arrays
Bot should download each file URL and upload it to the MAS portal
gps_breadcrumbs_available field is only relevant when issue_type is "GPS Control Deviation"
On success, always pass back the portal_ticket_id from the portal's confirmation page
