Original problem

What was built
artifacts/api-server/src/scripts/oneshot-resolve-duplicate-clusters-2026-05-13.ts — a resumable, cache-backed resolver that:

Scrapes every portal ticket via readPortalTicket
Buckets each group by ticket fleet status (canonical_open / all_closed_all_duplicates / all_closed_with_verdict / synthetic_only / needs_scrape)
Applies per-group transitions in transactions with full audit trail
Tags every audit row with backfillId='duplicate_cluster_resolution_2026_05_13' for surgical rollback
Cache: artifacts/api-server/exports/duplicate-cluster-scrape-cache-2026-05-13.jsonl (730 entries — survives across runs)
